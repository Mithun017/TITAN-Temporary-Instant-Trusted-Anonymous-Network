# ADR-0007: Single LeetCode-Inspired Visual Theme Without Switcher

**Status:** Accepted  
**Date:** 2026-11-08  

## Context
Initial design discussions contemplated offering multiple themes (e.g., GitHub, LeetCode, VS Code) or light/dark toggles. However, having a theme switcher dilutes the core covert concept: the entire product must authentically resemble a coding-practice environment.

## Decision
Enforce a single, consistent LeetCode-inspired dark interface across the entire application shell, Problem catalog, Problem 7 detail workspace, and Contest sharing arena. No theme switcher or secondary visual language is provided.

## Consequences
- Immediate visual familiarity for software engineers.
- High visual density, subtle neutral surfaces, and authentic coding workspace aesthetic.
- Reduced styling surface area and zero theme-synchronization bugs.
